# Documentation index

* `FORMATS.md` - current reference for the three file formats (Serum 1 `.fxp`, Serum 2 `.SerumPreset`, Vital `.vital`): offsets, tables, LFO layouts, modulation source ids, and how each claim was verified.
* `serum2_fx_survey.md` - survey of Serum 2 FX racks across a preset corpus, with the per-module parameter units and the Vital mapping that `serum2_fx.py` / `fx_common.py` implement.
* `FIXTURE_PRESETS_TASK.md` - recipe for the single-change fixture presets in `DebugPresets/`, which fixtures exist, and which tests cover them.
* `FINDINGS_AND_PLAN.md` - historical investigation log and plan (validated against the plugin, Vital's source and the corpus); sections 10-11 record what was resolved.
* `HISTORY_initial_plan.md` - the original improvement plan, superseded by `FINDINGS_AND_PLAN.md`; kept for context.

The top-level `README.md` covers installation, usage and the converter's limits.
